API GroundLink

GroundLink - это вымышленный сервис. Эта страница является примером документации, который показывает, как я структурирую справку по REST- и WebSocket-API. Здесь не описаны реальные системы, эндпоинты или данные клиентов.

Обзор

API GroundLink даёт программный доступ к сети наземных станций. С его помощью можно находить космические аппараты, доступные для отслеживания, бронировать сеансы связи на конкретной антенне и получать телеметрию в реальном времени во время пролёта.

API использует два транспорта:

ТранспортНазначениеБазовый адрес
REST поверх HTTPSЗапросы к каталогу и операции бронированияhttps://api.groundlink.example/v1
WebSocket поверх TLSНепрерывная передача телеметрии во время пролётаwss://stream.groundlink.example/v1

Все запросы и ответы используют application/json. Все метки времени указаны в UTC в формате ISO 8601, например 2026-03-14T09:20:00Z.

Машиночитаемая спецификация REST-части — openapi.yaml (OpenAPI 3.0).

Аутентификация

API использует аутентификацию по bearer-токену. Передавайте токен в заголовке Authorization в каждом запросе. 

Authorization: Bearer <access_token>

Получить токен можно в консоли оператора, в разделе Access keys.

СвойствоЗначение
Срок жизни токена12 часов
Права доступа (scopes)catalog:read, schedule:write, telemetry:read
ТранспортТолько HTTPS. Запросы по обычному HTTP отклоняются.
Не встраивайте токены в клиентские приложения. Токен даёт все назначенные ему права. Храните токены на стороне сервера и меняйте их, если есть подозрение на компрометацию.

Для WebSocket-эндпоинта передавайте тот же токен как query-параметр, потому что браузерные WebSocket-клиенты не могут задавать собственные заголовки:

wss://stream.groundlink.example/v1/telemetry?access_token=<access_token>

Лимиты запросов

ОбластьОграничение
Запросы к каталогу120 запросов в минуту на токен
Запросы бронирования30 запросов в минуту на токен
Подключения телеметрии4 одновременных подключения на токен

При превышении лимита API возвращает 429 Too Many Requests с заголовком Retry-After, который указывает, сколько секунд подождать перед повтором.

Список аппаратов

Возвращает космические аппараты, которые ваша организация вправе отслеживать, с ближайшим прогнозируемым пролётом для каждого.

GEThttps://api.groundlink.example/v1/satellites

Query-параметры

ПараметрТипОписание
statusstring Фильтрует результат по состоянию аппарата. Одно из значений: operational, commissioning, maintenance, decommissioned. Если не указан, возвращаются все состояния.
station_idstring Возвращает только аппараты, видимые с указанной наземной станции.
limitinteger Максимальное число записей в ответе. Диапазон 1–200. По умолчанию 50.
cursorstring Курсор пагинации из поля next_cursor предыдущего ответа.

Пример запроса

curl --request GET \
  'https://api.groundlink.example/v1/satellites?status=operational&limit=2' \
  --header 'Authorization: Bearer <access_token>'

Ответ 200 OK

items[].next_pass.aosstringНачало связи (AOS), UTC. См. AOS.
items[].next_pass.losstringПотеря связи (LOS), UTC. См. LOS.

Ошибки

400 Bad Request

Query-параметр задан неверно или выходит за диапазон, например limit=500.

Сверьте значения параметров с таблицей выше и повторите запрос.

401 Unauthorized

Заголовок Authorization отсутствует, задан неверно или токен истёк.

Получите новый токен в консоли оператора и повторите запрос.

403 Forbidden

Токен действителен, но у него нет права catalog:read.

Запросите это право у администратора вашей организации.

Бронирование сеанса связи

Резервирует антенну на один пролёт. Запрашиваемый интервал должен попадать внутрь прогнозируемого пролёта, возвращённого методом Список аппаратов, а антенна должна быть свободна на этот интервал.

POSThttps://api.groundlink.example/v1/schedules

Тело запроса

ПолеТипОбязательноеОписание
satellite_idstringДаАппарат, с которым нужно установить связь.
station_idstringДаНаземная станция, которую нужно зарезервировать.
startstringДаНачало сеанса, UTC. Не раньше AOS пролёта.
endstringДаКонец сеанса, UTC. Не позже LOS пролёта.
purposestringНетОдно из значений: telemetry, command, payload_download. По умолчанию telemetry.
priorityintegerНетДиапазон 1–5, где 1 - наивысший. Используется для разрешения конкурирующих запросов. По умолчанию 3.

Пример запроса

curl --request POST \
  'https://api.groundlink.example/v1/schedules' \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "satellite_id": "sat_7Kq2",
    "station_id": "gs_north",
    "start": "2026-03-14T09:22:00Z",
    "end": "2026-03-14T09:30:00Z",
    "purpose": "payload_download",
    "priority": 2
  }'

Ответ 201 Created

ПолеТипОписание
schedule_idstringИдентификатор брони. Используется для открытия потока телеметрии.
statestringconfirmed, если антенна зарезервирована, pending, если запрос конкурирует с бронью более высокого приоритета.
satellite_idstringАппарат, которому принадлежит сеанс.
station_idstringЗарезервированная наземная станция.
startstringПодтверждённое начало сеанса, UTC.
endstringПодтверждённый конец сеанса, UTC.
created_atstringВремя создания брони, UTC.
 
{
  "schedule_id": "sch_R48tvQ",
  "state": "confirmed",
  "satellite_id": "sat_7Kq2",
  "station_id": "gs_north",
  "start": "2026-03-14T09:22:00Z",
  "end": "2026-03-14T09:30:00Z",
  "created_at": "2026-03-13T15:02:11Z"
}
Бронь не окончательна, пока не подтверждена. Если state равно pending, опрашивайте бронь, пока она не станет confirmed или rejected. Не открывайте поток телеметрии для неподтверждённой брони.

Ошибки

400 Bad Request

Не указано обязательное поле или интервал некорректен, например end раньше start или окно выходит за пределы прогнозируемого пролёта.

Сверьте интервал с полем next_pass для аппарата и повторите запрос.

401 Unauthorized

Токен отсутствует или истёк. Получите новый токен и повторите запрос.

403 Forbidden

У токена нет права schedule:write либо ваша организация не имеет доступа к запрошенной наземной станции.

409 Conflict

Антенна уже забронирована на пересекающийся интервал запросом равного или более высокого приоритета.

Выберите другой интервал, другую наземную станцию или более поздний пролёт.

429 Too Many Requests

Превышен лимит запросов на бронирование. Подождите число секунд из заголовка Retry-After и повторите запрос.

Подписка на телеметрию

Открывает WebSocket-соединение, которое передаёт кадры телеметрии во время забронированного пролёта. Используйте этот эндпоинт вместо опроса: кадры приходят по мере того, как их принимает наземная станция, обычно с частотой 1 Гц.

WSSwss://stream.groundlink.example/v1/telemetry?access_token=<access_token>

Открытие потока

После установки соединения отправьте сообщение подписки с указанием брони:

{
  "action": "subscribe",
  "schedule_id": "sch_R48tvQ",
  "channels": ["power", "attitude"]
}
ПолеТипОбязательноеОписание
actionstringДаsubscribe или unsubscribe.
schedule_idstringДаПодтверждённая бронь для трансляции. Должна быть в состоянии confirmed.
channelsarrayНетКаналы телеметрии для получения: power, attitude, thermal, payload. Если не указаны, передаются все доступные каналы.

Сервер подтверждает подписку:

{
  "type": "subscribed",
  "schedule_id": "sch_R48tvQ",
  "channels": ["power", "attitude"]
}

Кадры телеметрии

Пока пролёт активен, сервер присылает по одному сообщению на кадр:

{
  "type": "telemetry",
  "schedule_id": "sch_R48tvQ",
  "received_at": "2026-03-14T09:22:03Z",
  "channel": "power",
  "values": {
    "bus_voltage_v": 27.8,
    "battery_soc_pct": 84,
    "solar_array_current_a": 3.12
  }
}
ПолеТипОписание
typestringТип сообщения: subscribed, telemetry, pass_ended или error.
received_atstringВремя приёма кадра наземной станцией, UTC.
channelstringКанал, к которому относится кадр.
valuesobjectИзмерения конкретного канала. Имена полей и единицы зависят от канала.

Когда аппарат уходит за горизонт, сервер присылает финальное сообщение и закрывает соединение:

{
  "type": "pass_ended",
  "schedule_id": "sch_R48tvQ",
  "los": "2026-03-14T09:30:00Z",
  "frames_delivered": 478
}

Обработка соединения

СитуацияПоведение сервераЧто должен делать клиент
Простой соединенияПрисылает ping-кадр каждые 30 секунд.Отвечать pong-кадром. Соединения, пропустившие два ping, закрываются.
Разрыв сигнала во время пролётаПрекращает передачу кадров, соединение держит открытым.Ждать. Разрывы в несколько секунд на низком угле места - это норма.
Обрыв соединения посреди пролётаБуферизует до 60 секунд кадров.Переподключиться и подписаться заново. Буферизованные кадры воспроизводятся один раз.
Пролёт завершёнПрисылает pass_ended, затем закрывает с кодом 1000.Не переподключаться по этой брони.

Коды закрытия соединения

КодЗначениеЧто делать
1000Пролёт завершён штатно.Ничего.
4001Токен отсутствует, недействителен или истёк.Получить новый токен и переподключиться.
4003У токена нет права telemetry:read либо бронь принадлежит другой организации.Проверить право и schedule_id.
4009Бронь не в состоянии confirmed.Дождаться подтверждения брони и переподключиться.
4029Слишком много одновременных подключений для этого токена.Закрыть существующий поток и переподключиться.

Коды ошибок

Ошибки REST имеют единый формат ответа:

{
  "error": {
    "code": "window_conflict",
    "message": "The requested interval overlaps a confirmed reservation.",
    "request_id": "req_9f2c1b"
  }
}

Указывайте request_id при обращении в техподдержку, он идентифицирует конкретный запрос в логах сервера.

HTTP-статусКодПричина
400invalid_parameterПараметр задан неверно или вне диапазона.
400window_outside_passЗапрошенный интервал не входит в прогнозируемый пролёт.
401token_expiredТокен доступа больше не действителен.
403scope_missingУ токена нет необходимого права.
404not_foundНет аппарата, станции или брони с указанным идентификатором.
409window_conflictАнтенна уже забронирована на пересекающийся интервал.
429rate_limitedПревышен лимит запросов для этой области.
500internal_errorНепредвиденный сбой на стороне сервера. Повторить с экспоненциальной задержкой.

Глоссарий

ТерминОпределение
AOSAcquisition of signal, начало связи. Момент, когда наземная станция впервые устанавливает радиосвязь с аппаратом во время пролёта.
LOSLoss of signal, потеря связи. Момент, когда радиосвязь прерывается, обычно когда аппарат уходит за горизонт.
Сеанс связиИнтервал, зарезервированный на конкретной антенне для связи с конкретным аппаратом.
Угол места (elevation)Угол между горизонтом и аппаратом, в градусах. Чем выше угол места, тем обычно устойчивее связь.
Наземная станцияПлощадка с одной или несколькими антеннами для связи с космическими аппаратами.
ISO 8601Международный формат даты и времени. Этот API использует UTC с завершающим Z, например 2026-03-14T09:20:00Z.
NORAD IDПубличный каталожный номер, присвоенный объекту на околоземной орбите.
Пролёт (pass)Период, в течение которого аппарат виден с данной наземной станции.
Кадр телеметрииОдин набор измерений, переданный аппаратом в один момент времени.
